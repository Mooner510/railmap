# 13.70-13.72 Route Search Diagnostics / Timetable Import / Result Comparison

## 적용 범위

이 패치는 현재 제공된 current zip 안에 포함된 `apps/editor` 파일 기준으로 다음 작업을 묶어 반영한다.

- 13.70: 경로검색 품질 진단 기반
- 13.71: 시간표 CSV import 리뷰 보강
- 13.72: 경로 후보 비교 준비도 표시

현재 코드에는 public web의 다중 경로 후보 비교 UI가 존재한다. 이 문서는 editor의 데이터 품질 진단, 시간표 import 리뷰, 후보 비교 준비도에 추가된 범위를 기록한다.

## 13.70 경로검색 품질 진단

`수기 데이터 감사` 탭에 `경로검색 품질 진단` 카드를 추가한다.

진단 항목:

- 시간표 우선 계산: 연결된 열차 시간표와 정차 패턴 수
- 성능 fallback: 수기 노선 중 성능값이 없는 노선 수
- 환승 edge: 환승 시간표가 미완성인 환승 그룹 수
- 시간 순서: 이전 역보다 빠른 시각이 발견된 시간표 수

## 13.71 시간표 import 리뷰 보강

시간표 CSV import 리뷰에서 미매칭 역을 단순 문자열로만 보여주지 않고, 정차 패턴 안의 유사 역 후보를 표시한다.

- 미매칭 입력 역명 표시
- 입력된 도착/출발 시각 유지
- 후보 역 버튼 클릭 시 pending 반영 목록으로 이동
- 이미 pending에 있는 역이면 중복 제외로 이동
- 열차번호/운행일 중복 경고에 실제 중복 후보 이름 표시

## 13.72 경로 후보 비교 준비도

`수기 데이터 감사` 탭에 경로 후보 비교 기준별 준비도를 추가한다.

- 최단 시간: 시간표 또는 성능 fallback 데이터 존재 여부
- 최소 환승: 환승 그룹/환승 시간 데이터 존재 여부
- 시간표 우선: 정차 패턴과 열차 시간표 연결 여부

이 정보는 web 경로검색 결과 비교 UI를 만들기 전에 데이터가 비교 가능한 상태인지 빠르게 확인하기 위한 기반이다.
