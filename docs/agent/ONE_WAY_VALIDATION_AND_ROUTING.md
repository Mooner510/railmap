# 단방향 branch 검증 및 경로검색 반영

## 적용 범위

- `13.79.0`: 단방향 branch 데이터 검증
- `13.80.0`: 정차 패턴과 단방향 정합성 검사
- `13.81.0`: 공개 경로검색 단방향 근거 표시

## 데이터 검증

감사 탭은 활성화된 `branchRouteOverrides` 중 `forward` 또는 `reverse`인 branch를 검사한다.

- 정차역이 2개 미만인 단방향 branch
- `circular: true`와 단방향이 동시에 설정된 branch
- 정차 패턴의 역 순서가 branch의 허용 방향을 거슬러 가는 경우

문제가 있으면 위험 항목에 표시하며, branch 문제는 수기 노선 탭으로, 정차 패턴 문제는 정차 패턴 탭으로 이동한다.

## 경로검색 표시

경로 그래프의 일반 이동 edge에 branch의 `routeDirection`을 보존한다.

- 품질 진단에 단방향 구간 수 표시
- 계산 근거에 `단방향 허용 방향` 표시
- 결과에 단방향 구간이 포함되면 반대 방향에서는 우회하거나 결과가 없을 수 있음을 안내
- 노선 상세의 단방향 배지는 실제 기점·종점 이름 기준으로 표시

## 운영 원칙

하나의 branch 안에서 일부 구간만 단방향이면 방향이 바뀌는 지점에서 branch를 분리해야 한다. 방향은 `stationIds` 또는 canonical `routeStops`의 저장 순서를 기준으로 한다.
