# Manual data audit dashboard

editor의 `감사` 탭은 수기 데이터와 경로검색 준비 상태를 한 화면에서 확인한다.

## 점검 항목

- 수기 노선/지선 개수
- 환승 그룹과 환승 시간 누락
- 정차 패턴과 시간표 연결 상태
- 시간표의 유효 시각 부족과 역순 시각
- 없는 역 참조
- 노선 성능값 누락
- 기존 검증 패널 이슈 수
- 최단 시간/최소 환승/시간표 우선 후보 비교 준비도

## 수정 진입

위험 항목은 단순 텍스트가 아니라 관련 작업 탭으로 이동하는 버튼이다.

- 환승 시간 누락 → `환승`
- 정차 패턴/시간표 문제 → `정차 패턴`
- 성능값 누락 → `수기 노선`
- 구조 검증 문제 → `검증`

개별 문제 객체를 자동 선택하는 기능은 후속 단계에서 추가한다.
