# Route Search Regression Cases

## 범위

공개 웹 경로검색 결과에서 현재 경로를 회귀 검증 기준으로 저장하고, 같은 출발역·도착역을 다시 검색했을 때 기존 기준과 비교한다.

## 저장 항목

- 출발역과 도착역
- 예상 소요 시간
- 환승 횟수
- 경유 stationId 순서
- 저장 시각

브라우저 `localStorage`에 최대 50개를 저장한다. 서버 데이터나 production bundle에는 검증용 데이터를 섞지 않는다.

## 확인 필요 판정

다음 중 하나라도 발생하면 `변경 확인 필요`로 표시한다.

- 예상 시간이 기준보다 3분 초과 증가
- 환승 횟수 증가
- 경유 stationId 순서 변경

현재 결과가 의도된 개선이라면 `기준 갱신`으로 새 결과를 기준으로 저장한다.
