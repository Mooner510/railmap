# Web map interaction and route UX

Version: 13.91.0-13.94.0

## Changes

- Keep every visible station interactive at all zoom levels with a dedicated transparent hit layer.
- Prefer station selection over line selection when both overlap.
- Apply railway category filters to map lines and stations, not only list/search results.
- Dim non-selected lines, stations, and transfer groups instead of removing them.
- Keep dimmed map objects interactive so route origin/destination can still be selected directly.
- Reduce audit dashboard wrapping with compact row layouts and fixed numeric columns.
- Keep route result summary concise and move diagnostics/regression/debug information behind disclosure controls.
