# 단방향 노선 구간 입력 및 경로검색 반영

## 목적

6호선 응암순환 구간처럼 특정 branch가 한 방향으로만 운행하는 경우를 수기 데이터에 저장하고 공개 웹 경로검색에 반영한다.

## 데이터

`branchRouteOverrides[].routeDirection`을 사용한다.

- `bidirectional`: 양방향
- `forward`: 편집기에 표시된 정차역 목록의 위에서 아래 방향
- `reverse`: 편집기에 표시된 정차역 목록의 아래에서 위 방향

기존 데이터에 값이 없으면 `bidirectional`로 취급한다.

## 편집기

노선 branch 검사 화면의 `운행 방향` 카드에서 방향을 선택한다. 정차 순서를 변경해도 기존 방향 설정은 유지된다.

## 공개 웹

경로 그래프 생성 시 허용된 방향의 ride edge만 생성한다. 반대 방향 이동은 해당 branch를 통해 탐색되지 않는다.

## 주의

한 branch 안에서 일부 구간만 단방향이고 나머지는 양방향이라면 branch를 운행 방향이 같은 구간 단위로 분리해야 한다.
